# Adopt a Pet - Python Flask Practice

This project is part of Codecademy's Build Python Web Apps with Flask course.
The app is a simple pet adoption website built with Flask. Users can visit the home page, browse available pets by type, and open a detail page for each pet to see its image, breed, age, and description.

## What I Practiced

- Creating a basic Flask application
- Defining routes with dynamic URL parameters
- Organizing data in Python and displaying it in the browser
- Building simple HTML responses from Flask routes
- Adding navigation links to make the app easier to move through
- Running a Flask app locally instead of inside the Codecademy workspace, including basic setup with a virtual environment and dependencies
